# Glossário

Extraído da seção 1.3 do ERS ("Definições, Siglas e Abreviações").

| Sigla | Significado |
|---|---|
| ERS | Especificação de Requisitos de Software |
| ERP | Enterprise Resource Planning (Sistema de Gestão Integrada) |
| CRM | Customer Relationship Management (Gestão de Relacionamento com o Cliente) |
| SGBD | Sistema Gerenciador de Banco de Dados |
| MVC | Model-View-Controller, padrão de arquitetura de software |
| RF | Requisito Funcional |
| RNF | Requisito Não Funcional |
| CMV | Custo da Mercadoria Vendida |
| RN | Regra de Negócio (numeração usada em cada estória, ex: RN01) |

## Termos de domínio (não estavam no ERS como sigla, mas aparecem sempre)

- **Estória de Usuário**: unidade de requisito no formato "Como
  `<perfil>`, quero `<ação>`, para `<objetivo>`", seguida de
  funcionalidades contempladas e regras de negócio.
- **Snapshot**: cópia fixa de dados no momento de uma conversão (Orçamento
  → Contrato → Evento), que não se atualiza com edições futuras na origem.
- **Adendo**: registro de alteração feita no orçamento original depois que
  ele já virou contrato — não altera o contrato, documenta a divergência.
- **Ficha de Produção**: painel operacional gerado a partir do Evento,
  reunindo cardápio escalado, equipe e equipamentos para orientar a
  execução do evento.
