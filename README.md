# Fogo de Chão Buffet Experience — ERP

Sistema de gestão sob medida para o Fogo de Chão Buffet Experience,
desenvolvido como projeto de estágio supervisionado (FIPP/Unoeste).

## Stack
- Backend: C# / ASP.NET Web API
- Frontend: React / Next.js (TypeScript)
- Banco de dados: MySQL

## Para desenvolvedores (humanos ou agentes)

Este projeto usa Claude Code como assistente de desenvolvimento. Antes de
mexer em qualquer coisa, leia `CLAUDE.md` na raiz — ele indica onde está
cada tipo de documentação (`docs/` para requisitos e arquitetura, `ai/`
para o estado de trabalho do agente).

A especificação de requisitos completa (ERS) está em `docs/requisitos/`,
organizada por módulo de negócio.
